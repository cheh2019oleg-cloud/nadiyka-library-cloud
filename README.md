# Бібліотека Надійки — інструкція збірки

## Що є в проєкті
- `www/` — сам застосунок (HTML/CSS/JS)
- `package.json`, `capacitor.config.json` — конфігурація Capacitor
- `tools/convert.bat` — на випадок, якщо колись знадобиться перекодувати відео (зараз не обов'язково, файли вже в mp4)

## Крок 1. Встанови залежності
Відкрий термінал у папці проєкту (`nadiyka-library`) і виконай:
```
npm install
```

## Крок 2. Додай Android-проєкт
```
npx cap add android
npx cap sync android
```
Це створить папку `android/` — саме її будеш відкривати в Android Studio.

## Крок 3. Дозволи в AndroidManifest.xml
Відкрий `android/app/src/main/AndroidManifest.xml` і перевір, що всередині тега `<manifest>` є (додай, якщо немає):
```xml
<uses-permission android:name="android.permission.INTERNET" />
```
Плагін вибору файлів (`@capawesome/capacitor-file-picker`) сам працює через системний провідник Android і додаткових дозволів на читання всієї пам'яті не потребує — це і є причина, чому обрали саме такий підхід замість прямого доступу до сховища.

## Крок 4. Відкрий в Android Studio
```
npx cap open android
```
(або відкрий папку `android/` вручну через Android Studio → Open)

Дай Gradle синхронізуватись (перший раз може зайняти кілька хвилин).

## Крок 5. Збери APK
Android Studio → **Build → Build Bundle(s) / APK(s) → Build APK(s)**
Готовий файл зʼявиться в:
```
android/app/build/outputs/apk/debug/app-debug.apk
```
Скопіюй цей файл на телефон Надійки (через USB, Telegram-собі, Google Диск — як зручно) і встанови (може попросити дозволити "встановлення з невідомих джерел" — це нормально для власного apk).

## Як це працює для Надійки
1. Відкриваєш застосунок
2. Тиснеш **➕ Додати файли**
3. Вибираєш один або кілька файлів з телефону
4. Аудіо (mp3) само летить у **Музику**
5. Відео (mp4) — застосунок питає, в яку категорію покласти (можна вибрати існуючу або створити нову)
6. Готово — файл одразу з'являється в списку, без перезбирання apk

## Якщо копіювання файлу не спрацювало
Деякі версії Android повертають файл у форматі `content://...` замість звичайного шляху. Плагін файл-пікера зазвичай сам конвертує це в реальний шлях (`copyFile`), але якщо побачиш помилку копіювання в тості — напиши мені, розберемось з конкретною версією Android/плагіна.

## Якщо щось не збирається
Найчастіші причини:
- Не встановлена Java (JDK 17) — Android Studio зазвичай пропонує встановити сам при першому відкритті проєкту
- Стара версія Android Studio — онови через Help → Check for Updates
- Помилка з плагіном `@capawesome/capacitor-file-picker` при sync — напиши мені точний текст помилки, підберемо або іншу версію, або альтернативний плагін
